# PBZDamageLab — 影之刃零 伤害实验室

一个 UE4SS Lua mod：召唤训练木桩，把每一击拆成各个伤害乘区，并实时显示你身上的饰品有没有在生效。面板不接管鼠标，开着也能正常转视角、正常战斗。

English: [README.md](README.md)

版本 1.0.0

## 需要

- 影之刃零 Steam 版 26367565（引擎 CL 302256）。其他版本会在面板上提示“未经验证”，可能无法正常工作。
- 影之刃零专用的 UE4SS，例如 Nexus 上的 “UE4SS For Phantom Blade Zero” 1.0.3。

## 安装

1. 先装好影之刃零专用的 UE4SS。
2. 把 `PBZDamageLab` 文件夹复制到 `ue4ss/Mods/`（跟 `mods.txt` 同一层）。
3. 在 `ue4ss/Mods/mods.txt` 里加一行 `PBZDamageLab : 1`，放在 `Keybinds` 那一行之前。
4. 如果装了 “PBZ Damage Test” 木桩 mod，请把它改成 `: 0`，避免同时召唤出两个木桩。

## 按键

可以在 `config.ini` 里修改（改完重启游戏）。键名按 UE4SS 的写法：Insert 是 `INS`，Delete 是 `DEL`（写 `INSERT`、`DELETE` 也认）。不要用 F10 和 `~`（UE4SS 控制台），也不要用 F11（游戏全屏切换）。

| 按键 | 作用 |
|---|---|
| F6 | 显示 / 隐藏面板 |
| F7 | 在面前召唤木桩（再按一次会把它移到面前） |
| F8 | 重置统计 |
| F9 | 移除木桩 |
| F1 / F2 / F3 | 把这一轮存为方案 A / B / C，对比每段连招的平均伤害 |
| F4 | 清空对比 |
| Insert（config.ini 里写 `INS`） | 实战模式：同时统计你对所有敌人（包括 Boss）造成的伤害 |
| Home | 定时测试：按下后打出第一击开始计时，持续 `TimedSeconds` 秒（默认 30）。计时中再按 = 提前结束，准备中再按 = 取消 |
| End | 把这一轮的命中数据导出成 CSV（只在按下时导出），保存在游戏目录 `platform\steam\ue4ss\Mods\PBZDamageLab\exports\` |

## 面板内容

- **统计**：命中数、总伤害、杀气削减、最高一击、各武器伤害占比、当前连招（停手 3 秒后算新的一段）及 DPS。杀气相关的行只在实战模式下显示（木桩没有杀气条）。处决伤害不计入。同类兵器共用的招式（空中攻击、完美闪避等）会记到同一段连招里下一个武器专属招式的武器上，所以刚换武器时也能记对。
- 木桩是游戏里开发者留下的只挨打木桩：不还手、不格挡、没有杀气条，固定在召唤的位置。
- **最近命中**：`伤害 = 基础 × 独立 × (1 + 加算) × (1 + 增幅)`，取的是这一招起手时的数值。
- **饰品**：你装备的所有饰品，按类型上色（攻击黄、辅助蓝、生存红）。攻击类会显示所在乘区；正在生效时标签显示亮绿，条件不满足时显示暗灰。舞扇、同心双鱼佩、绝望护符还会显示实时加成。

## 伤害公式（木桩实测）

`伤害 = 基础 × 独立乘区 × (1 + 加算池) × (1 + 增幅池)`

- **独立乘区**：妙手千钧 / 妙手连环 / 妙手在握、残破容器、武器等级加成，跟所有加成相乘。
- **加算池**：舞扇。池内相加。
- **增幅池**：碧血云天、同心双鱼佩、筋力绑带、绝地求生令、雪与血。池内相加。
- 两个池之间相乘（实测 1.6 × 1.35 = 2.16）。
- 一招的伤害在这一招开始时就锁定了。多段攻击中途触发的增益，要到下一招才生效。
- 标为“受击加算”“增伤”的乘区来自游戏数据，还没实测它们跟其他乘区怎么叠加。

## 已知限制

- 饰品名和武器名来自游戏本地化；面板本身的文字只有中文和英文。
- 实战模式只统计攻击数据属于玩家的命中，部分召唤物或饰品附带的额外伤害可能统计不到。
- 换武器后，如果这段连招只打了共用招式就停手，这几下会记到换之前的武器上。

## 反馈问题

把 `config.ini` 里的 `Debug` 改成 `true`，重启游戏，重现问题后把 `ue4ss/UE4SS.log` 发过来。默认 `Debug = false` 时，mod 只记录启动信息和错误。
